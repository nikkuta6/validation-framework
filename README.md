# Validation Framework

Учебный Java-фреймворк для валидации объектов на основе:
- собственных аннотаций (`@NotNull`, `@Email`, `@Min`, `@Max`, `@Size`);
- паттерна **Chain of Responsibility**.

## Что уже реализовано

- Базовая модель ошибок валидации (`ValidationError`).
- Контекст валидации (`ValidationContext`) для передачи данных по цепочке обработчиков.
- Абстрактный обработчик `AbstractValidationHandler` с поддержкой связывания `setNext(...)`.
- Рабочий обработчик `NotNullHandler`.
- Класс `Validator`, который:
    1. Обходит поля объекта через reflection.
    2. Формирует контекст.
    3. Запускает цепочку обработчиков.
    4. Возвращает список ошибок.
- Демонстрационный пример в `demo/Main`.

## Текущий статус

Сейчас в реальной цепочке подключён только `NotNullHandler`.
Аннотации `@Email`, `@Min`, `@Max`, `@Size` и соответствующие обработчики созданы как заготовки, но их логика и включение в цепочку пока не завершены.

## Идея расширения

Чтобы добавить новое правило валидации:
1. Создать/доработать аннотацию.
2. Реализовать новый `...Handler extends AbstractValidationHandler`.
3. Подключить его в `Validator.buildChain()` через `setNext(...)`.

После этого правило автоматически будет применяться ко всем полям, где стоит соответствующая аннотация.
